停用账号不再读取数据或接收提醒，既有会话与流式连接撤销。三种角色都不引入案件级隔离、团队或部门可见范围。首版仅支持同一 Windows 系统账号切换应用账号。

通知来源共享，投递/展示/已读按账号独立。通知接口以服务端会话 user_id 约束查询和更新，客户端不能指定其他账号或用他人投递 ID 越权；普通通知接口对管理员也不例外。普通界面仅取得必要的脱敏配置，完整系统设置仍只对管理员开放，不能为兼容旧界面降低设置接口权限。

“解除引用”保留文件本体；“统一备份恢复”恢复成套数据库/文件，继续保留在首版，区别于暂缓的单案件/单文件删除恢复。只读账号允许本人密码和通知状态操作，不获得共享业务写权限。

复杂模块的关闭优先于角色授权，管理员也不能绕过；保留代码与历史数据不意味着开放其查询和修改端点。精简律师费必须使用独立字段白名单及响应投影，不能直接放开整个旧 fees Router。

折扣表现、金额舍入、付款枚举及受保护历史费用的具体映射留待 Phase 2 前技术规则确认；不据此加入分期、付款流水、开票或审批。
